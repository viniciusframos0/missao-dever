# Missão Dever 🎯

O dever de casa virou jogo. Cada missão é feita a partir de uma atividade real da escola.

**Abrir:** https://viniciusframos0.github.io/missao-dever/

## Missões
| Missão | Disciplina | Série |
|---|---|---|
| Simulado SisPAE | Matemática | 2º ano |
| Leilão de Jardim | Português | 2º ano |

## Como adicionar uma missão
1. Coloque o jogo em `atividades/<nome-da-pasta>/index.html`.
2. Adicione um item em `atividades.js`.
